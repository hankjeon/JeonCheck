# 분석기 회귀 테스트

저장소 루트에서 .NET 10 SDK로 실행합니다.

```sh
dotnet run --project tests/JeonCheck.Analysis.Tests
```

외부 테스트 패키지나 WPF 런타임이 필요 없는 콘솔 테스트입니다. 실패 시 종료 코드 1을 반환합니다.
실제 분석기 소스를 연결해 최소 AST의 검출/비검출 사례와 dump XML 파싱 경로를 검사합니다.
한글 설명 DB의 필수 필드, 등급 표시, 빈 예시 안내, 헤더 누락 노트 및 미등록 진단 처리도 검증합니다.
규칙별 요약의 집계·정렬, 코드 미리보기, 검색·분류·예외 상태 연동 및 초기화도 검증합니다.
Windows용 Cppcheck 실행 및 GUI 통합 검증은 포함하지 않습니다.
