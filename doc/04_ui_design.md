# 04. 화면 구성 및 동작

## 테마와 레이아웃

WPF 다크 테마를 사용합니다. 코드 폰트는 내장 D2Coding이며 폴백은 Cascadia Mono, Consolas, Malgun Gothic입니다. JetBrains Mono는 현재 내장 폰트가 아닙니다.

상단 2단 툴바 아래에 왼쪽 소스 트리, 중앙 코드 뷰어·결과 탭, 오른쪽 진단 상세를 배치합니다. 패널 사이는 분할 바로 크기를 조정합니다.

```text
프로젝트 새로 만들기·열기·저장·샘플 | 규칙 설정·분석·취소·정보
타겟 | C 표준 | 매크로 | --force | Clang-Tidy
┌────────────────┬──────────────────────────────┬──────────────────┐
│ 검사 대상 트리  │ 파일명·줄 통계·외부 편집기     │ 선택한 진단 상세  │
│ 추가·제거       │ 읽기 전용 코드 뷰어           │ 규칙·정책·메시지  │
│ ↓ 제외 / ↑ 포함 ├──────────────────────────────┤ 한글 상세 해설    │
│ 참조 코드 트리  │ 결함 | 규칙별 요약 | 노트 | 예외│ 위반·개선 예시    │
└────────────────┴──────────────────────────────┴──────────────────┘
상태 메시지 | 선택 타겟 아키텍처
```

## 툴바와 소스 트리

- 프로젝트 새로 만들기·열기·저장·샘플 로드와 규칙 설정, 분석 시작·취소, 프로그램 정보 기능을 제공합니다.
- 타겟·C 표준·사용자 매크로·`--force`·Clang-Tidy 옵션을 선택합니다. TI DSP에 대한 Clang 모델 제한은 [데이터 명세](03_data_spec.md)에 설명합니다.
- 검사 대상과 비대상/참조 트리는 각각 폴더·파일 추가와 제거 버튼을 제공합니다. 선택 항목을 `비대상으로 제외` / `검사 대상으로 포함` 버튼으로 이동합니다. 대상 지정 체크박스는 없습니다.
- 대상 트리의 결함 배지는 현재 필터를 통과한 진단 수를 나타냅니다. 참조 트리는 헤더 검색에 사용하며 그 파일의 진단을 일반 대상 결과에 직접 표시하지 않습니다.

## 코드 뷰어

| 상태 | 상태바 / 배경 | 의미 |
| --- | --- | --- |
| 분석됨 | `#2EA043` / `#122119` | dump에 분석 토큰이 있는 줄 |
| 미검사 | `#484F58` / `#161618` | 원본 코드 토큰은 있으나 분석 토큰이 없는 줄. 회색 이탤릭과 `[미검사]` 표시 |
| 오류 | `#F85149` / `#3B1D20` | 현재 표시 진단에 Error가 하나 이상 있음 |
| 경고 | `#D29922` / `#342814` | 그 외 결함·규칙 위반이 있음 |
| 예외 | `#8957E5` / `#1F192C` | 표시할 활성 진단 없이 해당 줄에 예외 항목이 있음 |
| 기본 | 투명 | 공백·주석 등 또는 분석 정보가 없는 줄 |

상태 우선순위는 활성 진단 → 예외 → 분석됨 → 미검사 → 기본입니다. 현재 검색·분류 필터가 활성 진단과 줄 표시에도 영향을 줍니다. 분석됨 표시는 모든 규칙 검증이나 분기 검사의 완료를 보장하지 않습니다.

같은 줄에 진단이 3개 있으면 `[첫 규칙ID +2]` 배지를 표시하고, 배지에 마우스를 올리면 툴팁에 모든 진단의 규칙·심각도·메시지를 나열합니다. 팝업은 코드 위가 아닌 배지 위에서만 표시되며, 빈 내용과 검사 완료 줄 팝업은 표시하지 않습니다. Error가 하나라도 있으면 줄은 오류 색상이지만 배지 대표 규칙은 첫 항목입니다. 코드 줄을 직접 선택하면 첫 진단을 상세 대상으로 선택하며, 결과 목록에서 선택한 같은 줄의 다른 진단은 유지합니다.

줄 통계는 총 물리적 줄 수, 분석됨·미검사·결함·예외 줄 수를 표시합니다. 결함 통계는 진단 수가 아닌 **줄 수**입니다. 분석 비율은 수집된 분석됨/미검사 줄 집합으로 계산하며 전체 소스의 규칙 커버리지나 테스트 커버리지가 아닙니다.

`이 줄 예외`는 현재 줄의 진단들에 예외 키를 추가합니다. `다시 검사(복원)`은 예외를 해제해 기존 분석 결과를 다시 표시하는 동작이며, 엔진을 새로 실행하는 버튼은 아닙니다. 코드에는 C 구문 하이라이팅(주석·문자열·키워드·자료형·숫자·전처리기)을 적용하고, 파일 인코딩은 UTF-8·CP949·EUC-KR 중에서 자동 판별하며 코드창 우측 하단 버튼을 눌러 바꿀 수 있습니다.

## 결과 영역의 네 탭

### 1. 결함 및 규칙 위반

- 검색어와 분류 필터를 제공합니다. 검색 대상은 규칙 ID·제목·메시지·파일명이며 대소문자를 구분하지 않습니다.
- 심각도·분류·규칙 ID·파일명·줄·검출 메시지를 표시합니다. 열 제목을 클릭해 정렬할 수 있습니다.
- 항목 선택 시 해당 파일·줄로 이동하고 오른쪽 상세를 갱신합니다. 열 번호도 진단 모델에 유지하지만 코드 뷰어는 문자 단위가 아닌 줄 단위로 이동합니다.
- 우클릭으로 해당 규칙의 파일·줄 예외 또는 규칙 전체 OFF를 설정합니다. 예외 키에 열이 없어 같은 파일·줄·규칙의 모든 열이 함께 제외됩니다.

### 2. 규칙별 요약

- 기존 결함 탭과 같은 검색어·분류 필터를 공유합니다. ON/OFF와 예외 상태도 같은 결과 집합에 적용합니다.
- 헤더에는 `규칙 ID · 한글 규칙명 · N건`을 표시합니다. 규칙은 건수 내림차순, 동률이면 ID 순입니다.
- 그룹을 펼치면 파일 경로·줄·열과 코드 한 줄을 표시합니다. 같은 파일명이어도 전체 경로로 구별합니다. 하위 항목은 파일·줄·열 순입니다.
- 건수는 진단 항목 수입니다. 같은 줄의 같은 규칙도 서로 다른 열의 진단이면 별도로 셉니다. 서로 다른 규칙은 각각의 그룹에 표시합니다.
- 하위 항목 선택 시 원본 진단을 선택하여 코드와 상세 설명으로 이동합니다. 파일 누락 시 상태 메시지로 안내하며 코드 미리보기에도 읽기 실패를 표시합니다.
- 코드 미리보기는 요약 갱신 시 현재 파일에서 읽습니다. 파일 변경으로 해당 줄이 없으면 안내를 표시합니다.
- 갱신 후에도 계속 표시되는 그룹은 접기 상태를 유지합니다. 검색으로 사라졌다가 다시 나타나는 그룹이나 새 프로젝트의 상태는 별도로 저장하지 않습니다.
- 결과가 없으면 빈 목록 안내와 0건 집계를 표시합니다.

### 3. 노트 / 누락 파일 안내

헤더 누락, 분석 범위 제한, 단독 헤더 분석, 실행 실패·dump 실패 안내를 모읍니다. 노트는 코드 결함과 별도로 분류되지만 분석 결과를 신뢰하기 전에 확인해야 합니다. 위치가 있는 노트는 선택 시 해당 코드 줄로 이동합니다. 노트 선택이 결함 상세 패널을 해당 노트로 전환하는 구조는 아닙니다.

### 4. 예외 항목

예외 키별 규칙 ID·파일 경로·줄·예외 처리 당시 메시지를 표시합니다. 개별 항목 또는 전체 예외를 복원할 수 있습니다. 열별 예외 목록은 아닙니다. 파일이 바뀌어 위치를 찾지 못한 항목은 상태 열에 확인 필요로 표시합니다.

## 오른쪽 상세 설명

선택한 진단의 규칙 ID·제목·분류·검출 메시지·한글 상세 설명·위반 및 개선 예시를 표시합니다. MISRA 규칙은 `MISRA 의무`, 나머지는 `프로젝트 정책`으로 구분합니다. 오류/경고/권고 심각도와 의무 수준은 별개입니다.

등록된 예시가 없으면 미등록 안내를 표시합니다. 개선 예시가 모든 타겟·값·프로젝트 정책에서 자동으로 안전하거나 모든 경고를 없앤다는 보장은 없습니다. 미등록 세부 ID도 원문과 개별 한글 해설 미등록 안내를 표시합니다. 발견한 ID는 런타임 룰셋에 기본 ON으로 추가되며, 검색·분류·예외 처리와 규칙 OFF를 적용할 수 있습니다. 선택 상태는 프로젝트에 저장·복원합니다.

## 규칙 설정 창

- 카테고리는 규칙 DB에서 구성하며 ID·제목·요약·상세 설명으로 검색합니다.
- 목록은 활성 여부·규칙 ID·분류·기본 심각도·표준 의무/프로젝트 정책·규칙명·한 줄 요약을 표시합니다. 검사 포함 체크박스는 한 번 클릭으로 켜고 끕니다.
- 목록 전체 선택/해제는 현재 필터에 해당하는 규칙만 변경합니다. `필수/우선 검토 선택`, `형변환 집중 선택`은 전체 규칙을 변경합니다.
- 아래 미리보기에서 상세 설명과 예시를 확인합니다. 빈 예시는 미등록 안내로 표시합니다.
- 현재 창은 원본 규칙 객체를 직접 수정하고 `확인 및 적용` 버튼으로 닫습니다. 별도 취소·원복 버튼은 없으며 닫기(X)로 변경을 취소한다고 안내하지 않습니다.
